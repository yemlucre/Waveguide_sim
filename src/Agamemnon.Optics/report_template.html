如何读图？

目标比例是需求，间距和长度是设计变量。改变几何参数，比较计算结果，得到一个可继续细化的理论候选。长度增加并不保证更接近目标。

03 / MODEL & ASSUMPTIONS

每个结论，都有它的假设。

本次物理参数全部自定义，数值设置用于控制计算精度。

ASSUMED · 非实测

传播方程

i ∂ψ/∂z = [ − (1 / 2k₀n₀) ∂²/∂x² − k₀(n² − n₀²) / 2n₀ ] ψ

k₀ = 2π/λ₀。ψ 是复数光场包络，z 是传播距离。其演化形式与薛定谔方程相同；这里计算的是光在结构中的传播。

指标定义与坐标

左侧功率：∫x<0|ψ|²dx；右侧功率：∫x>0|ψ|²dx。输入一次归一化为 1，传播中不再次归一化。

包含场尾部与辐射，不等于分离输出端口的导模效率。x = 横向，z = 传播方向；没有映射到设备 XYZ。当前忽略另一个横向维度。

05 / CAPABILITY & NEXT STEPS
它能仿真什么，还能走多远？
当前是一套专用示例与可复用传播内核；通用程度取决于模型、输入和验证范围。
目前的能力边界
已完整支持
两条平行高斯平板波导：间距扫描、长度搜索、半空间分光比例与候选数值验证。
底层接口可算
自由衍射、自定义输入场、固定横向折射率分布；单波导导模与传播已有科学测试。需要编写调用代码，当前配置入口仍针对双波导。
需要扩展验证
多个平行波导、非对称截面等可通过静态分布接口表达；还需场景输入、各通道模式指标和对应基准。
当前未实现
沿 z 变化的几何、弯曲与分叉、两个横向维度、完整三维、偏振、反射、非线性和真实损耗。当前一维单向标量模型不能直接给出这些结论。
从现在的仿真，到真正的器件
先把目标写成可计算指标，再给模型增加必要的几何与物理细节。每次增加能力，都需要新的验证案例。
目标比例 → 间距 / 长度 → 平行耦合区候选
→ 输入输出分离段 → 二维截面与模式效率
→ 容差分析 → 实验标定 → 加工路径与工艺
当前完成到“平行耦合区候选”。报告不会推导未标定的曝光、写入速度或实际加工路径。
模型基础参考：Optiwave：BPM 与傍轴假设。当前实现为分步傅里叶法，不是该文所述有限差分实现。
