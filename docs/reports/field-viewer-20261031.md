# 完整已保存光场的滑块查看器

日期：2026-10-31。沿用包0.2.0的数值模型和物理契约，新增独立显示模块，不修改RK4求解器、存储格式、稳定性限制或判据。示例全部物理参数仍为 `assumed_not_measured`。

## 使用与范围

`from waveguide_sim.viewer import view_field, view_npz`。仿真完成后执行 `view_field(result.field, result.axes_um, result.z_um)` 直接浏览内存中的全部已保存复场；已有文件执行 `python -m waveguide_sim.viewer 路径/fields.npz` 或 `view_npz(path)`，一次读取field及坐标，关闭文件后浏览，不重新传播、不写文件。

查看器包含x-z积分图、当前横截面强度、当前横截面包络相位，三个离散物理坐标滑块。z选择已保存截面，x/y移动十字线，底部显示所选点坐标、复场、强度与相位。强度色标全程固定，相位固定[-π,π]；零场相位文本为undefined。坐标及数组顺序沿用 `(z,x,y)`，长度µm，强度单位由输入场约定，不自动转成实测单位。

教程第4节和第9节保留静态PNG保存，再以 `SHOW_PLOT=True`、`INTERACTIVE_VIEWER=True` 默认打开查看器。关闭交互开关可显示静态图，关闭SHOW_PLOT只保存PNG。README、模型契约与能力清单同步更新；未注册为Agent工具。

默认 `STORE_EVERY=1` 保存每个传播步的完整横截面。“所有点”指已保存的离散计算网格；较大存储间隔无法恢复未保存截面。查看器不插值、不重新判断收敛，只支持两横向维度且每轴至少两个点。须有交互Matplotlib后端和足够内存容纳全部复场；不另外建立完整强度或相位体积，只逐面求积分图与色标上限，交互时计算当前截面。
