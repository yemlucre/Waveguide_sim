# Python场景工具交付（2026-10-30）

本轮将“自定义折射率与复光场只能直接调用Python内核”的缺口补齐为正式场景协议。求解器仍为标量傍轴分步FFT；未引入真实材料、输入光或波导测量数据，全部示例物理参数均 assumed_not_measured。

## 固定工具与可修改输入

- 根 `simulate.py`：纯Python入口，默认运行 scene_example.py，支持参数覆盖、输出目录、打开报告、全部测试。
- `src/Agamemnon.Optics/python_scene.py`：API_VERSION=1，Scene、可信模块加载、输入/折射率/目标场验证、参数扫描。
- `bpm.py`：新增共享 refinement_grids 与 index_factory 验证入口；传播方程、离散推进公式、周期边界及门槛未改。
- `run_bpm.py`：复用同一研究组织逻辑，自定义场景与旧高斯JSON共用逐候选数值验证；新增目标模板重叠、目标/折射率原始数组、相位/折射率报告、场景源归档和启动器哈希。
- `scene_example.py`：日常修改PARAMETERS；需要新空间表达式时只改场景函数。两条四次超高斯折射率增量、一条缓移；带幅度与相位的双光斑输入；假设高斯目标模板。`scene_scan_overrides.json`提供间距8/10/12µm的一维扫描示例。

用户不需要先有实测参数即可运行数学研究。常规变化不修改共用工具；真实数据获得后由场景函数定义物理坐标和插值/背景约定。模型边界内的“任意分布”并非任意电磁物理，限制和接口详见[Python场景契约](../agent/python-scenes.md)。没有Agent/MCP注册、设备接口、加工映射。

## 验证

先运行 `simulate-optics.ps1 -Test`：35项通过，约100.8秒。增加不设置设计指标、只计算光场的研究用例后，运行最终 `python simulate.py --test`：**36项通过，98.631秒**。现有报告临时目录测试使用此前已验证的本机权限执行，未跳过测试或修改科学门槛。完整日志在 `artifacts/optics/python-scene-validation/`。

7项新回归覆盖：

1. 随z均匀势的精确相位，检查双点数/同dx大窗口/半步长均使用正确网格的回调。
2. 不提供ROI/目标时，纯光场研究成功且不虚构最佳候选。
3. 相反倾角输入与指定解析复目标的相位敏感投影；匹配输入重叠约1，另一输入与解析值 exp[−(kwΔθ)²/4] 一致到10位小数。
4. 非高斯二维折射率、复输入、覆盖参数、不修改原参数、沿z折射率变化及完整收敛。
5. 非实数、非有限、超弱导引范围、错误形状折射率与无效场拒绝。
6. 未知参数、无效ROI、缺少目标与非法扫描拒绝。
7. 绑定原网格的数组在细网格预检时明确拒绝，避免把裁剪或错位当收敛。

初始相反倾角投影测试错误地预期<0.1，实际为0.331186210341953；改为精确解析值比较而非任意阈值，记录在 initial-failure.txt。所有求解器原有门槛保持不变。中间结果和失败记录均保留。
